📖 How Backtracking Works ▼
Step 1 — Try
Find an empty cell
Scan row by row. Pick the first empty cell. Try placing digit 1 first.
Step 2 — Check
Is this digit valid?
Check if the digit already exists in the same row, column, or 3×3 box. If not → place it and move to the next empty cell.
Step 3 — Backtrack
Dead end? Go back
If no digit 1–9 works → erase this cell, go back to the previous cell, and try the next digit. This is backtracking.
Step 4 — Done
No empty cells left
When findEmpty() returns null, the board is fully solved. Every digit passed validation → solution found!
Pseudocode
solve(board):
  cell = findEmpty(board)
  if cell == null:
    return true  // solved!

  for n = 1 to 9:
    if isValid(board, cell, n):
      board[cell] = n

      if solve(board):
        return true  // recurse

      board[cell] = 0  // backtrack

  return false  // trigger BT
